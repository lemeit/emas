Esta es la API pública de solo lectura que ya usa app.lemeit.ar/emas para mostrar los datos de las 4 estaciones meteorológicas de Saladillo (EET N°1, CFR, DC y CS). Cualquiera puede consumirla directamente, sin registro ni token: es de lectura, CORS abierto, y devuelve los mismos datos que ya son públicos en el portal.

Base URL: https://api.lemeit.ar/emas (el https://ema-saladillo-api.fisicai-eureka-01.workers.dev original sigue andando igual como respaldo directo, sin el prefijo /emas)

GET /rest/v1/:tabla

GET/rest/v1/mediciones_ema | mediciones_cfr | mediciones_dc | mediciones_cs

Mediciones crudas de una estación puntual. Cada fila es un parámetro (temperatura, humedad, presión, etc.) en un instante dado.

ParámetroDescripción
selectColumnas a incluir, separadas por coma (ej. codigo,parametro,valor,fecha_hora_ar). Si se omite, trae todas.
ordercampo.asc o campo.desc. Ordena por fecha (asc/desc).
limitTope de filas. Default 100, máximo 5000.
codigoeq.N — filtra por código numérico de parámetro (estación EET).
parametroeq.Nombre — filtra por nombre de parámetro (ej. eq.Temperatura).
horasVentana relativa a "ahora", en horas (ej. 720 = últimos 30 días). Se ignora si se manda desde y/o hasta.
desdeFecha/hora UTC de inicio, formato YYYY-MM-DD o YYYY-MM-DD HH:MM:SS. Rango absoluto en vez de relativo.
hastaFecha/hora UTC de fin, mismo formato que desde.
formatocsv para descargar CSV en vez de JSON.
curl "https://api.lemeit.ar/emas/rest/v1/mediciones_cfr?parametro=eq.Temperatura&horas=168"

curl "https://api.lemeit.ar/emas/rest/v1/mediciones_dc?desde=2026-08-01&hasta=2026-08-15&formato=csv" -O -J

GET /rest/v1/v_temperatura_comparativa

GET/rest/v1/v_temperatura_comparativa

Temperatura promedio por hora de las 4 estaciones en columnas paralelas (eet, cfr, dc, cs), para comparar entre sí.

curl "https://api.lemeit.ar/emas/rest/v1/v_temperatura_comparativa?horas=48"

GET /rest/v1/v_ema_armonizada

GET/rest/v1/v_ema_armonizada

Un mismo parámetro (temperatura, humedad, presión, viento, lluvia, etc.) normalizado entre las 4 estaciones, una fila por estación y hora.

ParámetroDescripción
parametroeq.Nombre — uno de: Temperatura, Humedad, Presion, Velocidad Viento, Rafaga, Direccion Viento, Lluvia, Punto de Rocio, Radiacion Solar.
horas / limit / formatoIgual que en /rest/v1/:tabla.
curl "https://api.lemeit.ar/emas/rest/v1/v_ema_armonizada?parametro=eq.Lluvia&horas=720"

Notas

No hace falta API key ni registro: los datos meteorológicos son públicos. Usá &formato=csv en cualquiera de las rutas de arriba para bajar directo un CSV en vez de parsear JSON. Los timestamps se guardan y devuelven en UTC (cada fila también trae fecha_hora_ar ya convertida a hora Argentina, cuando el select la incluye). Si vas a reutilizar estos datos públicamente, agradecemos que menciones como fuente a app.lemeit.ar/emas — Red Meteorológica de Saladillo.
